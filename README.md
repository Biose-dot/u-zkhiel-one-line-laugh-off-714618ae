# One-Line Laugh-Off

One funny line, no setup notes, no explanation: an inheritance of three things — the heirloom watch, the tools, and the Netflix password — and the punchline is which one actually gets used. The sentimental objects gather dust; the password works every single night.

> My grandfather left me his watch, his tools, and his Netflix password. The watch gathers dust. The tools gather dust. The password gets used every single night.
